# SeedQ crawl-media architecture

Status: fixture-verified, not production deployed. Firecrawl/Hermes credentials and live endpoint authorization were not available during implementation.

## Boundary

No crawler runs in Nakama/Goja or at question serve time.

`external worker → crawl/search adapter → policy + media + safety + deterministic QA → signed candidate ingest RPC → SeedQ pool → staged sets`

The worker contract supports fixture, Firecrawl discovery, and a versioned Hermes candidate API. Both external providers fail closed when configuration is absent. Firecrawl search results remain discovery records until an approved deterministic candidate transformer is configured; they are never ingested as questions. The older analytics Firecrawl RPC is unrelated market-intelligence code and must not be used for SeedQ serving.

## Job contract

Submit with `quizverse_seedq_crawl_job_submit`:

- `mode`, `topic`, `country_codes`, `locales`, `interest_tags`
- `target_difficulty`, `age_band`, `media_type`, `count`, `freshness_window_days`
- `allowed_domains`, `denied_domains`, `allowed_licenses`, `query_hints`, `source_strategy`
- `idempotency_key`, `crawl_budget`, `max_pages`, `max_assets`, `timeout_ms`, `max_attempts`
- `auth: {timestamp_ms, nonce, signature}` generated by the worker. The HMAC-SHA256 signature binds the RPC id and complete unsigned body, expires after five minutes, and is single-use. The shared secret is never sent.

Poll `quizverse_seedq_crawl_job_status`. Send sanitized batches to `quizverse_seedq_crawl_candidate_ingest`. Errors use `{ok, code, error_code, error, retryable}`.

## Source and legal policy

- Obey robots.txt and source terms. Never access login-gated, private, paywalled, or user-specific pages.
- The job requires a non-empty domain allowlist; private/loopback/link-local URLs and denied domains fail closed.
- Images require explicit creator, alt text, citation, license URL, and public-domain/CC/permission rights.
- Videos remain remote embeds. Require an embeddable URL, thumbnail fallback, and a legally available transcript URL or cited segment/timecode. Do not download or rehost video.
- External agent review is recorded as `agent_supplemental`, never human review.
- Candidate flags are claims from the trusted worker and are rechecked structurally by Nakama. Production workers must implement MIME magic-byte, redirect-chain, size, malware, media health, and age/safety probes before setting them.

## Operations

Run one bounded fixture job:

```sh
node scripts/seedq-crawl/worker.mjs --dry-run --job scripts/seedq-crawl/jobs/fixture-image.json
```

Production execution requires `SEEDQ_SERVICE_TOKEN` (32+ random characters) in both the worker secret and Nakama runtime env. Provider configuration is worker-only:

- Firecrawl: `FIRECRAWL_API_KEY`, `FIRECRAWL_BASE_URL`; optional `FIRECRAWL_ALLOWED_DOMAINS` (defaults to `firecrawl.dev`).
- Hermes: `HERMES_ENDPOINT`, `HERMES_TOKEN`, `HERMES_PROVIDER_MODE=candidate_api_v1`, and `HERMES_ALLOWED_DOMAINS`.
- Provider selection: `SEEDQ_CRAWL_PROVIDER=disabled|firecrawl|hermes`; production defaults to `disabled`.

Never forward provider credentials to Goja or log them. Endpoints must be public HTTPS URLs whose host matches the explicit provider allowlist; redirects are rejected.

Use a queue with bounded concurrency, exponential retry for 429/5xx/timeouts, the included per-provider circuit breaker, and a DLQ. Missing config returns `PROVIDER_DISABLED`; Firecrawl discovery without a transformer returns `PROVIDER_TRANSFORM_REQUIRED`. Alert on quarantine ratio, media-health failures, source latency/429s, crawl budget, and cost. Replaying the same idempotency key is safe; replaying an identical signed request is rejected.

No Kubernetes manifest is included because the repository has no published worker image/entrypoint. Add a CronJob only after the image, queue ownership, and secret names are approved.

## Personalization

Country is explicit ISO-3166/profile-locale only; IP and precise location are not used. Selection keeps the existing 60% country / 40% global target. Persisted topic, mode, and media history is used only at five or more valid samples. Interest-weighted rows are capped at 40%, leaving a 60% curriculum/diversity allocation including a 20% exploration floor. Quality, rights, safety, no-repeat, and mode media gates run first.

Each served question exposes `selection_reasons`; the response exposes geo basis, behavior sample count/signals, fallback reason, and exploration percentage.

## Unity media contract

Unity should:

1. Render by `question_type` and verify `media_mime` before loading.
2. For video, use `media_embed_url`, seek to `media_timecode_seconds` where supported, and show `media_thumbnail_url` until playable.
3. Prefetch only the next item, cache by `crawl_provenance.asset_hash`, and honor staged `expires_ms`.
4. On load error, use `media_fallback` (`thumbnail` or `hide_media`), keep answer controls usable, and submit a `broken_media` SeedQ review.
5. Display creator/license/citation from `crawl_provenance`; never treat `review_kind=agent_supplemental` as human review.
6. Purge account-scoped staged cache on account switch and preserve no-repeat/consume semantics.

## Verification

Focused local suite:

```sh
node scripts/test_seedq_crawl_media.mjs
cd data/modules && npm run build
```

After a local restart, run `node scripts/test_seedq_crawl_runtime.mjs` with the isolated runtime host and service token. It submits both fixture jobs, verifies each yields three sets at `set_size=4`, consumes/refills without repeats, and confirms coverage reports `crawl_images`, `crawl_videos`, `rights_approved`, and `media_healthy`. Then run the existing 15-check verifier and 23-case edge matrix. Production crawling remains blocked until an authenticated, allowlisted provider crawl passes all gates; fixture candidates must never be seeded into production.
