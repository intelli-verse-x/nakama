QuizVerse Path A — Automated YouTube-Driven Live Events

Zero-touch weekly loop: AI generates mystery videos, YouTube comments pick winners, events end themselves, and champions are crowned every Sunday — no human in the loop.

1 Daily Content Loop — the 3-Part Mystery

Runs 6× per day per region, fully automated.

⏰Daily Best-Guess Cronn8n

The Daily Best Guess 6x Cron workflow fires on a DST-safe schedule and calls the Content Factory quiz-shorts pipeline with the region + series part to generate.

🎬Quiz-Shorts Pipeline + Mystery RegistryContent Factory

Each mystery is a 3-part series tracked in quizverse_mystery_registry.py — clues, answer, video IDs, winner, and wrong guesses persist across parts so the story stays continuous.

Part 1 — Tease

2 clues. Ends with “First correct guess in the comments WINS.”

Part 2 — Build

4 clues. Script highlights real wrong guesses from Part 1 comments and hypes whether anyone has cracked it.

Part 3 — Reveal

Answer revealed. Script announces the actual winner by name — or “NOBODY got it!”

📤Publish via Postiz → YouTubePostiz / YouTube

Postiz publishes the rendered short. Its publish-status webhook calls back into automation.py → receive_publish_status, which extracts the YouTube video ID from the release URL and stores it on the mystery record (record_video_id()). Now the system knows exactly which video to scan for comments.

viewers comment their guesses
🕵️Comment Monitor — First Correct Guess WinsContent Factory

Before generating Part 2 / Part 3, quizverse_comment_monitor.py pulls comments through the YouTube Data API and fuzzy-matches every guess against the answer (exact substring, similarity ratio > 0.75, significant-word match). The earliest correct commenter is the winner; the funniest wrong guesses get featured in the next video.

2 Live Events End Themselves

No creator or admin has to press “End”. Two independent sweepers guarantee it.

🔁Primary — every minuten8n

Live Event Auto-End Sweep workflow calls the Nakama RPC creator_event_auto_end_sweep every 60 seconds. Silent when nothing to do; posts to Discord when events end or fail.

🛟Fallback — every 5 minKubernetes

CronJob live-events-auto-end (3-59/5 * * * *) hits the same RPC, so events still end even if n8n is down. The sweep is idempotent — double-firing is safe.

🏁finalizeEndedEvent()Nakama

For every published event past scheduledAt + duration: read the event leaderboard, assign prize tiers, persist status ended, queue gift-card fulfillments, and emit EVENT_ENDED (with a stable idempotency key). The same code path serves the manual “End” button — Path B behaviour is untouched.

🎞️Recap Video PipelineContent Factory

The existing quizverse-event-ended n8n webhook triggers the recap video — winners, top plays, and a call-to-action for the next event — published back to YouTube automatically.

3 Sunday — Weekly Champions

Every play all week is silently tracked. Sunday evening, the crowns drop.

📈All Week — Silent TrackingNakama

Every answer submission emits SCORE_SUBMITTED on the EventBus. The weekly-champions module listens (Path B submit RPCs untouched) and updates the regional weekly_total_score leaderboard, player streaks, and daily-activity records.

📅Sunday Crons — per regionn8n

Weekly Champions Calculate fires Sunday 20:00 IST (India) and 17:00 ET (USA), calling Nakama RPC weekly_champions_calculate for that region, then posts the winners board to Discord.

👑Winners Crowned + Prizes QueuedNakama

Gift cards are queued through the fulfillment pipeline, XUT bonuses are granted directly, in-app notifications go out, and players claim via weekly_champions_claim.

🥇Champion

#1 on the regional weekly leaderboard. Premium gift card.

🥈Runner-Ups ×2

#2 and #3 on the weekly leaderboard.

🎯Top Guesser

Most correct Part-1 YouTube guesses this week (from the comment monitor).

🔥Streak King

Longest consecutive-day play streak.

🎲Lucky Draw

Random pick from every player active ≥ 3 days this week.

💰Top-20 XUT Bonus

Leaderboard positions 4–20 earn an XUT currency bonus.
